## 先回答你的疑问（基于代码核实）

**1. 那几个按钮有什么用？**
- `＋ 新对话`：清空当前消息流，开启一段新会话（旧会话自动存入历史）
- `📜 历史`：进入历史页，查看/恢复/删除过去的对话
- `+`（输入框旁）：打开能力面板——拍照、相册、聊天文件（上传作品给 AI 看）、AI 生图
- 截图里显示不全的原因已定位：MediaPanel 的卡片**没有 max-height 和滚动**（对比生图面板有 `max-height: 82vh; overflow-y: auto`），内容超过小屏视口就溢出且不可滚。修复：加 max-height + 内部滚动 + 底部安全区适配。

**2. 专属培养方向有结合吗？**
- **对话回答：已经生效**。你在培养方向页的选择会实时拼进 AI 的系统提示词（如「思维发散性」要求每题至少两种解法）。
- **但知识库检索：还没生效**——刚发现的缺口。推荐工具读了你的培养方向但只用来显示，没参与检索排序。本次将让检索结果按你的培养方向加权（如「艺术素养」方向会优先命中艺术类题目）。
- 年级同理：目前 AI 只知道"8-14 岁"，**不知道具体年级**。本次把 profile.grade 注入提示词，六年级学生会得到六年级难度的表述。

**3. 六年级学生上传教材/习题实现个性化？→ 可以，这是本次核心新功能（个人 RAG）**
- `+` 面板新增「📚 上传学习资料」：拍照识字（OCR）或粘贴文本 → 内容安全审核 → 存入个人知识库（openid 隔离，上限 50 条可删除）
- Agent 检索时个人材料与公共知识库合并检索、优先参考 → 真正实现"乔治懂这个用户"
- 你提到的联网搜索也确认做：输入框加 🌐 开关

## 实施内容（按执行顺序）

### A. UI 修复
- MediaPanel：card 加 `max-height: 80vh; overflow-y: auto` + 底部预留 ChatInput/TabBar 高度；两个分组标题合并为单列表（4 项，各带说明副标题）

### B. 灵感直达改为预填充（你选的方案）
- `useChatSession.restore()` prompt 分支不再自动发送，改为返回文本；learn 页 `setInputText(文本)` + Toast「已为你填好，点发送即可 ✨」

### C. 思考可视化（你选的方案）
- 思考中：气泡内文案按 2.5s 轮换（正在理解问题…→检索知识库…→整理思路…）
- 回复后：气泡下方显示本轮实际用的工具小标签（📚 知识检索 / 🎯 个性化推荐 / 🌟 探索积分 / 📁 作品归档 / 📝 学习小结）

### D. 个性化四件套
- **D1 年级注入**：deepseek.ts 拼 system prompt 追加「【用户画像】：X 年级学生」
- **D2 检索加权**：retrievalCore 新增 preferAbilities 加权（abilityIds 交集 +0.12），recommend/search 工具传入用户 currentAbility；补 2 个单测
- **D3 个人材料入库（最大块）**：
  - 云函数新分支 `type:"ingest"`：审核→写入 knowledge_base（`type:"material", source:"user", openid`）→单用户 50 条上限
  - 前端新组件 MaterialPanel（拍照 OCR / 粘贴文本 / 我的材料列表与删除）+ 新 API `src/api/knowledge.ts`
  - 检索改造：公共库（实例级 5min 缓存）+ 个人库（按 openid 缓存）合并检索；OCR 用 `cloud.openapi.ocr.printedText`（config.json 加权限；若环境未开通则降级提示改用粘贴，不阻塞）
- **D4 联网搜索开关**：ChatInput 加 🌐 toggle；开启时透传 webSearch 参数给 generateText（以 SDK 实际支持字段为准；若不支持则降级为提示词方案并如实说明）

### E. 顺手优化
- **E1 灵感池接知识库**：首页灵感卡从写死 6 条改为云端随机抽 quiz（失败回退本地文案）
- **E2 AI 生图一键收藏**：AI 图片消息加 ⭐ 收藏按钮，一键存入作品集（sendImage 时记录 prompt 作为作品标题）

## 验证与交付
每节点跑 `node --check` + `node --test` + `tsc --noEmit` + `build:weapp`；D3/D4 完成后你需重新部署云函数（云端安装依赖）并真机验证 OCR 与联网功能。
