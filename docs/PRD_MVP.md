# 桥智同学 MVP 前端 UI 与功能需求文档 (PRD)

## 1. 全局设计规范 (Design System)

- **主题色 Token**：
  - **主品牌紫 (Primary Purple)**：`#8B5CF6` / `#7C3AED`（Header 背景、主按钮）
  - **科技绿 (Accent Green)**：`#76C843` / `#22C55E`（选中的 TabBar、高亮标签）
  - **页面背景色 (Page BG)**：`#F8F9FA`
  - **卡片纯白 (Card BG)**：`#FFFFFF`（圆角 `16px`，带微阴影）
- **底部 TabBar 路由**：
  - `pages/learn/index` (学习 - AI 动态对话页)
  - `pages/home/index` (首页 - 项目宣传页，**默认进入的首页**)
  - `pages/profile/index` (我的 - 个人数据与勋章页)

---

## 2. 页面与组件详细拆解

### 2.1 首页 (`pages/home/index`) —— 默认入口宣传页
- **顶部 Header**：
  - 深紫背景，左侧展示“桥智同学” Logo 及标语 “青少年 AI 创意助手”，右侧黄色胶囊按钮 “🔔 通知”。
- ** Hero 欢迎卡片**：
  - 紫色渐变背景，标语：“👋 你好，未来创造者！让 AI 成为你的超级学习伙伴”。
  - 按钮：“✨ 开始 AI 创作”（点击跳转至学习页 `pages/learn/index`）。
  - 右侧配合桥智同学 3D 站立立绘。
- **项目介绍卡片**：
  - 徽章 `📖 项目介绍`，标题 `关于桥智同学`。
  - 内容：`培养 AI 时代产品经理思维：帮助青少年学会定义问题、判断结果、表达自己，成为未来数字世界的主动创造者。`
- **团队理念卡片**：
  - 徽章 `🏫 团队理念`，标题 `团队与理念`。
  - 内容：`由深圳大学科技工作室孵化，联合一线教育者与 AI 工程师共同打造。`
  - 标签组：`🎓 资深导师` | `🤖 AI 技术支持` | `📚 课程专家`
- **核心特色列表**：
  - 标题：`⚡ 核心特色`
  - 3 张独立卡片：
    1. `魔法指令卡` - 学会用精准语言指挥 AI，掌握 Prompt 工程核心技巧
    2. `AI 小法官` - 辨别 AI 输出好坏，培养批判性思维和结果判断力
    3. `3分钟新品发布会` - 像乔布斯一样，用 3 分钟清晰表达你的 AI 创意作品

### 2.2 学习页 (`pages/learn/index`) —— AI 对话交互页
- **顶部 Header**：
  - 深紫背景，标题 `AI 学习助手`，副标题 `桥智同学在线为你服务 ✨`。
- **IP 形象三状态控制 (`chatState`)**：
  1. **Idle 状态（默认未对话）**：
     - 中央展示大尺寸“桥智同学” 3D 立绘。
     - 问候文本：`你好！我是桥智同学 👏`。
     - 快捷 Prompt 胶囊按钮列表：`帮我出个谜题` | `什么是魔法指令？` | `教我写一个小游戏` （点击直接发送）。
  2. **Thinking 状态（AI 思考中）**：
     - 顶部形象切换为思考姿势立绘，区域显示“桥智同学正在思考中...”脉冲动画。
  3. **Chatting 状态（已产生对话）**：
     - 桥智同学 3D 形象**缩小**并固定在**左上角**。
     - 主体展示对话消息流（用户消息靠右，AI 回复靠左 Markdown 卡片）。
- **底部悬浮输入栏 (Floating Input Bar)**：
  - 纯白圆角输入框， Placeholder：`有什么我能帮您的吗？`。
  - 包含麦克风图标与紫色圆形发送按钮。

### 2.3 我的页 (`pages/profile/index`) —— 个人中心
- **顶部 Header**：深紫背景，标题 `我的`。
- **用户信息卡片**：
  - 用户头像、昵称 `未来创造者`、等级 `LV.3 学习达人`。
  - 网格数据：🎂 `10月12日` 生日 | 📚 `五年级` 学龄 | ⭐ `1,280` 积分。
- **荣誉勋章墙 (Honor Badges)**：
  - 横向滑动卡片：🚀 `未来创造者` | ⚖️ `AI 小法官` | 🙋 `提问大师` | 🔒 `待解锁`。
- **菜单功能列表**：
  - 🎨 `我的作品集 My AI Projects`
  - 📖 `学习记录 Learning History`
  - ⚙️ `设置与关于我们 Settings & About Us`

## 3. 代码架构与拆解要求
- `src/components/` 必须拆分为：`CustomTabBar`、`HomeHeader`、`PromptPill`、`ChatInput` 等微型组件。
- 每一个页面只做组件组合，逻辑控制放在 Hooks 或 API 层。
